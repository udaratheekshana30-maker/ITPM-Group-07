# DormDesk Laundry Management Subsystem

This is a dummy laundry management system built with React and Node.js. It allows students to monitor laundry machine availability and book slots in real-time.

## Project Structure

- `/backend`: Node.js Express server with in-memory machine status.
- `/frontend`: React application with a premium Glassmorphism UI.

## Getting Started

### Prerequisites
- Node.js installed on your system.

### Running the Backend
1. Navigate to the `backend` folder.
2. Run `npm install` (if node_modules are not present).
3. Start the server: `node server.js`.
4. The backend will be available at `http://localhost:5001`.

### Running the Frontend
1. Navigate to the `frontend` folder.
2. Run `npm install`.
3. Start the dev server: `npm run dev`.
4. Open your browser to the URL provided (default `http://localhost:5173`).

## Features
- Real-time status grid.
- Interactive booking system.
- Premium UI design.
